# Cleo Days

Installierbare Android-PWA: 12.–20. Oktober 2026 im Cleopatra Luxury Resort Makadi Bay.

Tagesabhängiges Programm, Soko-Abendbuffets, Shows, Aktivitäten, Preise, 14 Originalfotos, Favoriten und eigener Plan. Fotos und App-Shell sind offline cachebar.

**Android:** Öffne die GitHub-Pages-Adresse in Chrome → Menü → App installieren.

**Deploy:** GitHub Actions Workflow in `.github/workflows/deploy.yml`. Einmalig unter *Settings → Pages → Source: GitHub Actions* auswählen, falls nicht bereits aktiviert.

Hinweis: Unbestätigte Waterfront-Uhrzeiten sind ausdrücklich als offen markiert.
