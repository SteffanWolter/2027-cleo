# Cleo Days 🌴 — Android PWA

Our 12–20 October 2026 holiday companion for Cleopatra Luxury Resort Makadi Bay.

**Live app:** https://steffanwolter.github.io/2027-cleo/

## Features
- Egyptian hotel time, nine-day itinerary, daily entertainment, themed dinners, and activity schedule
- 14 original photographed hotel notices, zoomable and available offline after installation
- Prices, transfers, dining, annotations about uncertain hotel offerings and booking requirements
- Local saved plans, favorites, notes, JSON backup / import and ICS export
- Native-feeling Android UI: floating bottom tabs, large tap targets, safe-area layout, install prompt, adaptive motion and tactile feedback
- Installable PWA, custom icons, offline-first service worker; no sign-in or analytics

## Publishing
GitHub Pages is **successfully published from the `gh-pages` branch**. Changes intended for the site must be applied to `gh-pages` (or fast-forward that branch to a tested `main` commit) to trigger redeployment. Source files are also retained on `main`.
